# Планирование автомобильных перевозок (Проект №09)

**Участник:** [Твоё ФИО]
**Назначение программы:** Программа для составления планов перевозки по списку заказов и транспортных средств с учётом вместимости, расстояния и временных ограничений.
**Предполагаемые технологии:** Python (FastAPI/Flask) для бэкенда, SQLite/PostgreSQL для БД, HTML/JS (или Vue/React) для фронтенда. Для прототипа — Python.

## Инструкция по запуску (черновик)
1. Установить Python 3.10+
2. Установить зависимости: `pip install -r requirements.txt`
3. Запустить: `python main.py`
