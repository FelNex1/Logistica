# Планирование автомобильных перевозок (Проект №09)

**Учебный проект** по разработке программы планирования автомобильных перевозок с учётом ограничений. 
**Участники:** Трубачёв Никита, Муфтеев Саид.

## Назначение программы
Программа предназначена для составления планов перевозки по списку заказов и транспортных средств с учётом вместимости, расстояния и временных ограничений.
**Предполагаемые пользователи:** Логист, диспетчер, преподаватель-эксперт.

## Используемые технологии (текущий стек)
*   **Бэкенд:** Python 3.10+, Flask (создание API и рендеринг страниц).
*   **Фронтенд:** HTML5, Vanilla JavaScript (Fetch API), CSS3.
*   **Шаблонизатор:** Jinja2 (встроен во Flask).
*   **Хранение данных:** JSON-файлы (на этапе прототипа). В планах — переход на SQLite.
